## Search testing note

- For staging validation we are sharing the production Bonsai cluster, but not the production database.
- That is intentional: Elasticsearch indices are disposable and can be recreated from Postgres, while the database is the source of truth and should not be risked.
- Staging uses the `staging_pins` index prefix, so its search data stays separate from `production_pins` even on the shared cluster.
