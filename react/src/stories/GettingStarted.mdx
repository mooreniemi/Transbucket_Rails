# Getting Started

## Local development

1. Ensure your terminal has Node V24 running. You can check by running `node --version`. If node is not installed or the version is incorrect, [Download Node](https://nodejs.org/) or install via [NVM](https://github.com/nvm-sh/nvm) if managing multiple versions of node.
2. Once installed, run the following command:
    ```
    npm install
    ```
3. Run the build:
    * To run the application:
    ```
    npm run dev
    ```
    * To run Storybook:
    ```
    npm run storybook
    ```
