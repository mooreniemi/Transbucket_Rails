# Getting Started

## Local development

1. Ensure your terminal has Node V24 running. You can check by running `node --version`. Download Node or install via NVM.
2. Once installed, run the following command:
    ```
    npm install
    ```
3. Run the build:
    * To run the application:
    ```
    npm run dev
    ```
    * To run Storybook:
    ```
    npm run storybook
    ```
